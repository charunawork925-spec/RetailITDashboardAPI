Building a Chart
1. Choose a dataset from the left panel (Customers, Products, etc.)
2. Drag dimension fields (D) to the X axis — these are your categories
3. Drag measure fields (M) to the Y axis — these are your numbers
4. Click Run to see data. Charts auto-run on field drop too.
Widget Actions
▶ Run query   📋 Toggle data table   ⬇ Download CSV
🖼 Save chart as PNG   ⧉ Duplicate widget   ⤢ Resize
Cross-Table Analysis
To see Products by Month: set dataset to Products, then under "Join With" select Transactions. Now you can use fields from both tables.
Filters

Save & Share
